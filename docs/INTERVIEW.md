## 常见追问与回答方向

| 问题 | 回答要点 |
| --- | --- |
| 自洽体现在哪里？ | rho 依赖 psi；每次更新电势后浓度也变化，直到同一组未知量满足残差与边界 |
| 为什么不用耗尽近似一直画到底？ | 积累和反型中移动载流子重要，保留它们才能描述连续过渡 |
| 阈值怎么定义？ | 本项目以表面势 2phi_F 定义；数值根与耗尽近似公式相互核对 |
| 为什么准静态反型电容上升？ | 充分响应的反型电荷使额外栅压主要落在氧化层，电容向 Cox 靠近 |
| 高频曲线对应多少 Hz？ | 没有指定频率；它是冻结电子交流密度的近似，需要动态模型才能预测实际频率响应 |
| 为何网格不均匀？ | 界面附近浓度与电势变化最快，需要更密的空间采样 |
| 残差小能证明程序正确吗？ | 还要看独立参考、网格、守恒、边界与物理模型范围 |
| 为什么 Qg+Qs 不一定为零？ | 还可能有固定氧化层电荷，以及有限域后边界电位移 |
| 怎样证明没拿解析解充当数值解？ | 数值支路从零或前一偏压解出发，独立构建残差与雅可比；参考函数只用于验证与数据生成 |
| 参数能都一起拟合吗？ | 未知功函数、固定电荷、面积和噪声会引入相关性，应增加独立信息并检查可辨识性 |
| 0.31% 是测量精度吗？ | 是给定合成算例和噪声种子的掺杂提取误差，不是实测或普遍精度 |
| 你自己的贡献是什么？ | 按真实情况回答复现、重写、排错、验证和扩展，指出具体提交与学习日志 |
