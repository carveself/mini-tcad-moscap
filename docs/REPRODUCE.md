# 按难度复现：从能运行，到能自己解释和修改

参考实现已经完成。建议先完整运行一次，再在自己的分支或副本中逐段重写；保留每一步输出和你遇到的问题。下面的“完成标准”比运行成功更重要。

## 阶段 0：环境与基准（约半天）

按主 README 安装后运行：

```bash
python run_all.py
python -m unittest discover -s tests -v
```

完成标准：13 项测试通过；得到 7 张 PNG；`figures/data/synthetic_cv.csv` 有 61 行数据；`figures/cv.csv` 有 85 行数据。JSON 和 CSV 的数字不是截图，应该能直接核对。

记录 Python、NumPy、SciPy、Matplotlib 版本。不要用“图看着差不多”替代验证。默认电容是单位面积电容，尚未乘实际器件面积。

## 阶段 1：独立参考曲线（约 2-3 天）

```bash
python src/stages.py reference --output reproduction/01-reference
```

先阅读 `Device`、`reference_charge` 和 `reference_bias`。自己整理从体区电中性、玻尔兹曼浓度到片电荷和栅压关系的推导。用表格或你自己的绘图脚本画 `reference.csv`。

完成标准：能解释正栅压为什么排斥空穴；能说清 VFB 与 Vth；知道 `V_T` 表示热电压，`Vth` 表示阈值。默认 Cox 约 0.00345313 F/m²，解析阈值约 0.8553336 V。

动手：把厚度从 10 nm 改成 20 nm，先预测 Cox 变化，再验证。单位检查应得到 Cox 减半。

## 阶段 2：三种状态的非线性解（约 4-6 天）

```bash
python src/stages.py profiles --output reproduction/02-profiles
```

这个检查点固定使用 -0.25、0.4、1.05 V，分别对应默认器件的积累、耗尽和反型。它与完整绘图脚本按阈值自动选择的代表偏压略有不同，便于手算和逐步调试。

阅读 `charge_functions`、`system`、`solve_bias`。先用文字说明每一行残差对应哪个控制区间，再重写离散与雅可比。界面半格电荷、右端接地、固定电荷的符号都需要特别核对。

完成标准：三个偏压的表面势约为 -0.09427、0.31092、0.81385 V；残差低于 2e-10；能解释为啥牛顿法需要阻尼。自己检查 `Qg + Qox + Qs - D_bulk`。

动手：把 `initial` 设成与目标状态差距较大的有限数组，观察阻尼；在你自己的实验分支中暂时遗漏半格电荷，比较误差，然后恢复。把失败与修复记录写入学习日志。

## 阶段 3：C-V、参数扫描和可信度（约 4-6 天）

```bash
python src/stages.py cv --output reproduction/03-cv
```

先推导为什么电容是 dQg/dVg，再读灵敏度线性方程。比较准静态曲线与冻结电子响应的高频近似，解释二者在反型区的差别。高频曲线没有对应的指定测量频率。

完成标准：能自己重画网格收敛；区分非线性残差、空间离散误差、有限域影响和物理模型误差。默认相对 Cox 的最大 C-V 误差约 6e-5，而不是把它写成 6e-5 F/m²。

动手：预测并验证厚度、掺杂和正固定氧化层电荷对 C-V 的影响。正固定电荷使平带电压向负方向移动。找出浓度/有效态密度比值超过 0.05 的扫描点，说明经典统计为什么开始需要谨慎。

## 阶段 4：反推参数（约 3-5 天）

```bash
python src/stages.py extract --output reproduction/04-extraction
```

阅读 `run_extraction` 和 `fit_cv`。先画原始合成数据，再画拟合残差；注意真实数据生成模型与逆模型没有使用同一空间离散。已知温度、功函数差、固定电荷和面积归一化，只有两个自由参数。

完成标准：默认得到厚度约 11.99425 nm、掺杂约 1.20369e16 cm⁻³；你能解释对数参数、噪声权重、参数相关性和局部不确定度。不要把单个种子的误差写成方法对所有数据的保证。

动手：在自己的实验分支中更换种子、增加噪声或只保留耗尽区数据。记录参数误差和雅可比条件数，讨论为什么数据覆盖范围会影响可辨识性。不要覆盖已提交的基准数据后仍沿用旧报告。

完成一页学习日志：你重写了哪些函数、遇到什么失败、用了哪个独立检查、最后有哪些局限。选择至少一个自己的扩展实验，写清变量、预测、结果和解释。

使用 `INTERVIEW.md` 练习 5 分钟讲解。清楚说明参考实现的来源以及自己复现、修改和验证的部分。只有在独立理解并复现后，再按自己的实际贡献写简历。

## 排错顺序

| 现象 | 优先检查 |
| --- | --- |
| 一开始就找不到库 | 是否激活同一个虚拟环境，安装命令与运行命令是否使用同一个 Python |
| 表面势符号反了 | x 正方向、E=-dpsi/dx、栅边界中的 VFB 与 psi_s 符号 |
| 体区电荷不为零 | p0-n0=NA；cm⁻³ 转 m⁻³ 是否乘 1e6 |
| 牛顿发散 | 解析雅可比、指数溢出、阻尼和边界方程 |
| 残差很小但曲线不准 | 网格、计算深度、参考解以及模型假设 |
| 反演值离谱 | 面积/单位、偏压范围、已知 VFB 假设和噪声权重 |

阶段时间是学习安排建议，按你的基础调整。以能解释、改动并重新验证为完成标准。
